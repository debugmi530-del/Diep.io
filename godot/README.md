# Diep.io Clone — Godot 4 Port

Полный перенос игры Diep.io Clone с Android/WebView на движок **Godot 4**.

## Требования

- [Godot Engine 4.3+](https://godotengine.org/download/)

## Запуск

1. Открыть **Godot 4**
2. Нажать **Import** и выбрать папку `godot/`
3. Нажать **Play** (F5)

## Что реализовано

### Игровые механики
- Движение танка (WASD / мобильный джойстик)
- Прицеливание мышью / тачем
- Стрельба (ЛКМ / правая сторона экрана)
- Физика снарядов: рикошет, пробивание, взаимодействие пуль
- Урон корпусом при столкновении
- Регенерация HP
- Отдача при стрельбе

### Система уровней и классов
- 45 уровней с таблицей XP (точная копия оригинала)
- Выбор класса на уровнях 15, 30, 45
- **20+ классов танков:**
  - Basic → Skirmisher, Warlord, Sniper, Twin, Spinner
  - Shotgun → Blaster, Buster, Riot
  - Dreadnought → Colossus, Cruiser, Brawler
  - Triplet, Overlord, Cannon, Miner, Droner, Rocket, Smasher, Sprayer

### Типы снарядов
- **Normal** — обычный снаряд
- **Trap** — мина (залипает, урон при касании)
- **Drone** — дрон (преследует врагов)
- **Homing** — управляемая ракета
- **Bomb** — взрывной снаряд с радиусом поражения

### Фигуры (препятствия / XP)
17 видов фигур с точными значениями XP и HP:
Квадрат, Треугольник, Пятиугольник, Шестиугольник, Семиугольник, Восьмиугольник, Десятиугольник, Мега-пятиугольник, Ультра-полигон, Крашер, Альфа-пятиугольник, Легенда и др.

### Боты
- 30 ботов с ИИ (роуминг, погоня, бегство, атака фигур)
- Случайные имена и классы
- Автовозрождение ботов

### UI
- **HUD**: полоски HP и XP, уровень, очки, класс, убийства
- **Таблица лидеров** (топ-5 + позиция игрока)
- **Выбор класса** при апгрейде
- **Экран смерти** с таймером возрождения (3 сек)
- **Главное меню** с вводом имени
- **Мини-карта** (правый верхний угол)
- **Лента убийств** (kill feed)

### Мультиплеер
- WebSocket через relay-сервер (тот же, что в оригинале)
- Создание/вход в комнату по коду
- Синхронизация позиций, уровней, очков
- Встроенный чат

### Панель администратора (F12 + PIN)
- Спавн любых фигур рядом с игроком
- Спавн NPC-ботов любого класса

### Дополнительно
- Сетка мира 16000×16000 (точно как в оригинале)
- Красные стены-границы
- Автоспин для танка Spinner
- Вампиризм для Vampire
- Взрывная волна для Bomb

## Управление

| Действие | Клавиатура | Мобильный |
|----------|-----------|-----------|
| Движение | WASD | Левый джойстик |
| Прицел | Мышь | Правая сторона |
| Стрельба | ЛКМ | Правый тап/свайп |
| Авто-огонь | E | — |
| Адмін-панель | F12 | — |

## Структура проекта

```
godot/
├── project.godot          # Конфиг проекта Godot 4
├── icon.svg
├── scenes/
│   ├── Main.tscn          # Главная сцена (меню → игра)
│   ├── Game.tscn          # Игровая сцена (мир + HUD)
│   └── entities/
│       ├── Player.tscn
│       ├── Bot.tscn
│       ├── Bullet.tscn
│       └── Shape.tscn
└── scripts/
    ├── Main.gd            # Переход меню/игры
    ├── Game.gd            # Главный менеджер игры
    ├── data/
    │   ├── GameConfig.gd  # Все константы (XP, фигуры, цвета)
    │   └── TankData.gd    # Все классы танков со стволами
    ├── entities/
    │   ├── Tank.gd        # Базовый класс танка
    │   ├── Player.gd      # Управление игроком
    │   ├── Bot.gd         # ИИ ботов
    │   ├── Bullet.gd      # Снаряды (все типы)
    │   └── Shape.gd       # Фигуры-препятствия
    ├── ui/
    │   ├── HUD.gd
    │   ├── ClassSelect.gd
    │   ├── Leaderboard.gd
    │   ├── MainMenu.gd
    │   ├── DeathScreen.gd
    │   ├── AdminPanel.gd
    │   ├── Minimap.gd
    │   ├── WorldBackground.gd
    │   └── MultiplayerUI.gd
    └── network/
        └── MultiplayerManager.gd
```
